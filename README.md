# Hospital Management System

A Windows Forms application built with C# and Entity Framework for managing hospital operations including patients, doctors, and appointments.

## Features

- **User Authentication** - Secure login system with role-based access
- **Patient Management** - Add, view, edit, and delete patient records
- **Doctor Management** - Manage doctor information and specialties
- **Appointment Scheduling** - Book and manage patient appointments
- **Search Functionality** - Find patients quickly by name or phone number
- **Basic Reporting** - View today's appointments and statistics
- **Data Export** - Export appointments to CSV format
- **Database Integration** - Entity Framework with SQL Server

## Roles & Access

- **Administrators** - Full access to all features
- **Doctors** - Access to patient lists and appointments
- **Receptionists** - Patient registration and appointment scheduling

## Technology Stack

- **Language**: C#
- **Framework**: .NET Windows Forms
- **ORM**: Entity Framework
- **Database**: SQL Server / LocalDB
- **Architecture**: Multi-Document Interface (MDI)
 
 
##  Usage
    
- Login - Use provided credentials to access the system
    
- Manage Patients - Add new patients or update existing records
    
- Manage Doctors - Add and manage doctor information
    
- Schedule Appointments - Book appointments between patients and doctors
  
- Generate Reports - View daily appointments and statistics
    
- Export Data - Save appointment data to CSV files
